WSPR BEACON OVER WLAN

IC-705 setup

The radio is not in a data mode. The beacon sets USB-D itself before every slot, but the audio path below has to be set up by hand first.

  1. MENU → SET → Connectors → MOD Input → DATA MOD to WLAN.
  2. MENU → SET → Connectors → MOD Input → WLAN MOD Level to 25% as a starting point, then trim with TUNE until the radio's ALC meter stays at zero.
  3. Mode USB-D with filter FIL1. The beacon selects the mode, not the filter.
  4. RF power at or below 10 W. The beacon refuses to key above that, whatever the radio can do.
  5. Turn the monitor on if you want to see your own tone in the waterfall during transmission.
  6. Break-in off. WSPR keys through the network, not through VOX.

The transmitted power in the WSPR message follows the radio: turn the power knob and the reported value follows it, to the nearest legal WSPR level.
!

The radio is driven from somewhere else

One radio, one operator: JS8Call-ICOM and WSPR-Beacon both drive the transceiver through a single audio link, so only one page can run at a time.
