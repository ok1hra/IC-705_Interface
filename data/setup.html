WiFi eeprom
Connect the IC-705 to the same access point
  1. Enter your router's network name and password in SSID 1 / Password 1 above, then Save.
  2. On the radio, open MENU → SET → WLAN Set and set WLAN to ON.
  3. Set Connection Type to Station — this joins an existing router instead of the radio's own access-point mode.
  4. Open Access Point, scan the networks, pick the same SSID as in step 1, and enter its password.
  5. Keep DHCP ON so the router assigns the radio an address; note the IP Address shown in WLAN Set.
  6. Select Radio → TRX1 → LAN below and enter that IP. For LAN control also set Remote Settings → Network Control to ON and configure a Network User1 ID/password.
Both devices must be on the same access point for the interface to reach the radio.
