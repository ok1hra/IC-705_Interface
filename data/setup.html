Put the radio on the same network as this interface
  1. Enter your router's network name and password in SSID 1 / Password 1 above, then Save.
  2. Radios with a LAN socket (IC-7610, IC-9700, IC-7300MK2, IC-7760): connect an Ethernet cable from the radio to the same router. Leave DHCP ON and note the address the radio shows.
  3. IC-705 (wireless): open MENU → SET → WLAN Set, set WLAN to ON and Connection Type to Station. Under Access Point scan the networks, pick the same SSID as in step 1 and enter its password. Keep DHCP ON and note the IP Address shown in WLAN Set.
  4. Turn network control on. On the IC-705, IC-7300MK2 and IC-7760 it lives under Remote Settings; on the IC-7610 and IC-9700 the items sit directly under Network. Set Network Control to ON and configure a Network User ID and password.
  5. Select Radio → TRX1 → ICOM-LAN below, enter that address and those credentials, then press Test & identify radio — it reports whether the radio accepted the login and reads back its model.
Both devices must be on the same network for the interface to reach the radio. The DATA and WSPR pages carry a full per-radio setup guide behind their ? button.
